# Smart Task Manager

*Smart Task Manager* هو تطبيق بسيط يساعد المستخدمين على تنظيم وإدارة المهام اليومية بشكل فعّال وسهل. يهدف التطبيق إلى تحسين الإنتاجية من خلال توفير أدوات سهلة الاستخدام لإنشاء المهام، تعديلها، حذفها، وتصنيفها حسب الأولوية أو الوقت.

## الميزات

- إنشاء مهام جديدة مع عنوان ووصف ووقت محدد.
- تعديل أو حذف المهام.
- تصنيف المهام حسب الحالة (منجزة/غير منجزة).
- واجهة مستخدم بسيطة وسهلة الاستخدام.
- حفظ المهام محليًا أو في قاعدة بيانات (حسب المرحلة القادمة من التطوير).

> (قم بتعديل هذه القائمة حسب ما ستستخدمه)

- لغة البرمجة: Python / JavaScript / HTML & CSS
- قاعدة البيانات: SQLite / Firebase / LocalStorage
